## Цель

- Спроектировать мини-схему БД.  
- Заполнить её начальными данными.  
- Реализовать консольное меню из 5 пунктов для запросов к БД (включая `JOIN`).  

---

## Схема базы данных

Создать две таблицы:

### `category`

- `id` — `INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY`  
- `name` — `TEXT NOT NULL UNIQUE`

### `dish`

- `id` — `INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY`  
- `title` — `TEXT NOT NULL`  
- `price` — `NUMERIC(8,2)` (**> 0**)  
- `category_id` — `INT` (внешний ключ на `category(id)`, поведение при удалении категории — на ваше усмотрение: `SET NULL` или `RESTRICT`)

## Консольное меню (входная точка приложения)

При запуске скрипта должно появляться меню:

1. **Показать всё меню**  
   Отображение: *блюдо — цена — категория*.

2. **Показать блюда в ценовом диапазоне**  
   Пользователь вводит минимальную и максимальную цену.

3. **Поиск по началу названия (префикс)**  
   Пользователь вводит начало названия (регистронезависимо).

4. **Показать N самых дешёвых блюд**  
   Пользователь вводит целое число `N`.

5. **Категории и количество блюд**  
   Показать список категорий и количество блюд в каждой, включая категории без блюд.
